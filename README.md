# JamerGamer

A test of your skills, a test of your luck, a test of your patience.

## Play in your browser

**[cpaz54.github.io/JamerGamer](https://cpaz54.github.io/JamerGamer/)**

Works in Chrome, Edge, Firefox and Safari on a computer with a keyboard. The first load
downloads about 75 MB, then click the page to start. Your progress saves in the browser.
In the shooter chapter, click the game to aim with the mouse, and press Esc to let go of it.

## Download instead

To play without a browser, click the green **Code** button on this page, then **Download ZIP**, and unzip it.
Then follow the steps for your computer below.

## Play on Mac

1. Open the unzipped **JamerGamer-main** folder.
2. **Right-click** `build_mac.command`, choose **Open**, then click **Open** again.
   (macOS asks this for files downloaded from the internet. Double-clicking alone won't work the first time.)
3. A Terminal window builds the game. The first run takes a few minutes, then the game opens.
   - If a window asks to install **command line developer tools**, click **Install**, wait for it to finish,
     then do step 2 again.
   - If it says Python 3 was not found, install it from [python.org/downloads](https://www.python.org/downloads/),
     then do step 2 again.
4. To play again later, open **JamerGamer.app** in the `dist` folder (or run `build_mac.command` again).

## Play on Windows

1. Install **Python 3** from [python.org/downloads](https://www.python.org/downloads/).
   On the first installer screen, tick **"Add python.exe to PATH"**.
2. Open the unzipped **JamerGamer-main** folder and double-click `build_windows.bat`.
   If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.
3. A window builds the game. The first run takes a few minutes, then the game starts.
4. To play again later, double-click `build_windows.bat` again (it starts right away now),
   or run **JamerGamer.exe** in the `dist\JamerGamer` folder.

Your progress saves automatically. Press **Esc** in game for the pause menu and **F11** for fullscreen.
