# JamerGamer

A test of your skills, a test of your luck, a test of your patience.

Five games, one after another, introduced by the puppet master:

| # | Chapter | Controls |
|---|---------|----------|
| I | **Snake**: eat 20 apples | Arrows |
| II | **The Gauntlet**: 3 stages, then a 4-boss rush | A/D move, W/Space jump (S+jump drops through ledges), J attack |
| III | **Turn and Cough**: rhythm game | Hold Z X C V B, strum with Space (Tab on the intro screen switches to tap mode) |
| IV | **Jamer Quest**: a little Zelda-like | Arrows move, A sword, Q bow, E talk/open |
| V | **Hell Arena**: raycast shooter | WASD + mouse, click/Space to shoot, arrow keys also turn, Tab map |

Global keys: **Esc** pause menu (resume, restart chapter, volume, quit), **F11** fullscreen,
**`*`** developer skip (finishes the current chapter). In the platformer, **F1** skips the current stage or boss.

Progress saves automatically to `save.json`. From the title screen, *Continue* resumes where you
left off, including mid-chapter checkpoints, and *Chapters* replays anything you've unlocked.

## Setup

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

Jump straight to a part of the story with `python main.py --step <id>`, where `<id>` is one of
`intro snake pre_platformer platformer pre_rhythm rhythm pre_adventure adventure pre_doom doom finale end`.

## The rhythm chapter's song

The chapter plays **"From the End of the World"** by Electric Light Orchestra, from
`assets/rhythm/` (any audio file there with "end of the world", "electric light" or "elo" in its name).
The note chart is the original hand-tapped one, mapped onto the recording's measured 142 BPM beat
grid (see `jamergamer/rhythm/charts.py`).

If that file is missing, the chapter plays **"Cough Syrup"**, an original chiptune generated by
`tools/build_rhythm_track.py` with a chart that follows its melody note for note. If the timing
feels off on your machine, use `[` and `]` during the song to nudge the audio offset.

## Layout

```
main.py                    entry point
jamergamer/
  app.py                   window, fixed-timestep loop, scaling, pause menu
  story.py                 chapter order + all puppet-master dialogue
  scenes/                  title, cutscenes, snake, ending
  platformer/              levels.py (ASCII stage maps), bosses.py, player, physics
  rhythm/                  rhythm game + charts.py (original ELO chart preserved)
  adventure/               rooms.py (all Jamer Quest maps & text), world, actors
  raycaster/               world.py (map, zones, waves) + renderer/enemies
assets/                    all art, music and sound
tools/
  preview_levels.py        render platformer stages to PNGs
  slice_adventure_sprites.py  rebuild assets/adventure/sprites from the source sheets
  build_rhythm_track.py    regenerate the fallback song + chart
```

The Hell Arena is rebuilt from [DOOM-style-Game](https://github.com/StanislavPetrovV/DOOM-style-Game)
(MIT, see `assets/doom/LICENSE-DOOM-style-Game`).
